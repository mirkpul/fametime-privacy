1. Cosa raccoglie Fametime

Fametime raccoglie solo informazioni di utilizzo locale, lette direttamente dal sistema operativo del dispositivo su cui è installata:

  • app aperte e tempi di utilizzo (via PACKAGE_USAGE_STATS),
  • timestamp delle sessioni (per rilevare uso notturno, micro-scatti, rebound, maratone e frequenza),
  • nomi delle app installate/avviate (niente contenuti, niente dati personali).

Fametime non raccoglie: posizione, contatti, messaggi, foto, audio, identificativi di rete, annunci, dati sanitari.

2. Dove vivono i dati

Tutti i dati restano sul dispositivo. Non esistono server: nessun cloud, nessun invio di dati a terzi, nessuna sincronizzazione. Se disinstalli l'app, i dati di utilizzo vengono eliminati con lei.

3. Finalità

Le informazioni servono esclusivamente a:

  • calcolare lo score di salute digitale (0-100),
  • riconoscere pattern di utilizzo compulsivo,
  • mostrare all'utente spiegazioni educative sul proprio uso.

La finalità è una funzionalità richiesta e centrale dell'app: Fametime non può funzionare senza i dati di utilizzo locale.

4. Condivisione con terzi

Zero. Non condividiamo dati con nessuno: nessun anunciante, nessun partner, nessun servizio di analytics. Fametime non integra nessun SDK di terze parti (no Firebase, no Analytics, no ad network).

5. Scudo anti-disinstallazione

Con lo scudo attivo, Fametime richiede una work profile / Profile Owner per impedire la rimozione non autorizzata. Questo meccanismo è gestito localmente dal sistema operativo Android: il profilo di lavoro non contiene dati personali e può essere rimosso in qualsiasi momento dall'utente (o dal dispositivo con accesso fisico + PIN, tramite reset di fabbrica). Nessun dato viene inviato a un server MDM: il provisioning è locale.

6. Minori

Fametime è progettata anche per supportare l'uso di dispositivi da parte di minori, con l'attivazione e supervisione di un adulto. I dati raccolti sono sempre e solo i dati di utilizzo locale descritti al punto 1.

7. Tuo diritto

Essendo i dati interamente sul dispositivo, puoi:

  • accederli: apri l'app (schede Oggi / Protezione),
  • eliminarli: disinstalla l'app (o, con scudo attivo, rimuovi il work profile / reset di fabbrica),
  • richiedere informazioni: contatta lo sviluppatore al numero sopra.

8. Modifiche

Questa policy può essere aggiornata. La versione aggiornata sarà pubblicata alla stessa URL con una nuova data di aggiornamento.
